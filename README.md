> [!IMPORTANT]
> VKSound — **неофициальный проект**, не связанный с VK. Доступность функций зависит от VK и его веб-сервисов; изменения на стороне VK могут временно повлиять на работу приложения.

## Возможности

- **Ваша музыкальная библиотека** — музыка VK, недавние треки, поиск, плейлисты VK и локальные плейлисты.
- **Очередь под контролем** — меняйте порядок треков перетаскиванием в очереди, своей музыке и доступных для редактирования плейлистах.
- **VK Микс** — рекомендации и управление текущей лентой; порядок в Миксе меняется только в текущем сеансе.
- **Плеер для рабочего стола** — мини-плеер, системный трей, горячие клавиши и медиаклавиши.
- **Больше контроля над звучанием** — эквалайзер, тексты песен и перемотка по волне трека.
- **Музыка рядом** — офлайн-кеш, локальные аудиофайлы и история прослушивания.

## Быстрый старт

1. Нажмите **«Скачать для Windows»** вверху страницы. Установщик появляется там после успешной автоматической сборки.
2. Запустите `VKSound-Setup-latest.exe` и завершите установку.
3. Откройте VKSound и подключите VK в окне приложения.
4. Выберите музыку и слушайте. Локальные аудиофайлы и кешированные треки доступны в соответствующих разделах.

## Частые вопросы

**Это официальный плеер VK?**  
Нет. VKSound — независимый проект и не представляет VK.

**Нужно ли устанавливать Node.js или Python, чтобы пользоваться приложением?**  
Нет. Они нужны только для разработки или сборки из исходного кода. Готовый установщик включает необходимые компоненты.

**Как обновить установленное приложение?**  
Откройте **Настройки → Обновление приложения → Проверить обновления через GitHub**. VKSound проверит последнюю сборку, скачает установщик и контрольную сумму, проверит файл и предложит запуск установки. Можно также скачать установщик вручную со страницы релизов.

**Как обновляется ссылка на установщик?**  
После успешной сборки в основной ветке GitHub Actions обновляет релиз и файл `VKSound-Setup-latest.exe` вместе с SHA-256 контрольной суммой.

## Сборка и разработка

Для локальной сборки нужны Windows 10/11 x64 и интернет:

```powershell
.\Build-App.cmd
```

Скрипт получает портативные Node.js и NSIS в `.tools`, проверяет контрольные суммы, запускает тесты и создаёт установщик в `artifacts`.

GitHub Actions автоматически проверяет и собирает проект при отправке изменений. Установщик прикрепляется к запуску workflow как artifact; после успешной сборки в основной ветке он также публикуется в релизе и становится доступен по ссылке вверху README. Секреты или ключи VK для сборки не нужны.

Для разработки:

```sh
npm install
npm test
npm start
```
