# Сборка VKSound для Windows

## Требования

- Windows 10/11 x64
- Интернет для первой сборки
- VS Code (редактор; компилятор установщика скрипт получит сам)

## Сборка из VS Code

Откройте папку проекта в VS Code и запустите в терминале:

```powershell
.\Build-App.cmd
```

Скрипт автоматически скачает в `.tools` портативные Node.js и NSIS, проверит контрольные суммы, установит зависимости в папку проекта, запустит тесты и соберёт приложение и установщик. Системные программы вручную устанавливать не нужно. Ответьте `y`, когда скрипт спросит о начале сборки.

Результаты:

- Установщик: `artifacts/VKSound-Setup-1.0.1.exe`
- Портативная версия: `artifacts/win-unpacked` (переносите папку целиком)

Установщик задаётся в `installer.nsi`; NSIS распаковывается в `.tools\nsis-3.13` без системной установки. Подробности сборки записываются в `build-gui.log`.

Если загрузка NSIS не проходит проверку SHA-256, скрипт теперь пробует две официальные ссылки SourceForge и `curl.exe` (если он доступен), а затем выводит фактическую контрольную сумму и размер ошибочного файла. Не отключайте проверку и не подменяйте ожидаемый хэш. При повторной ошибке попробуйте другую сеть или проверьте прокси/антивирус.

## Сборка на GitHub

Workflow `.github/workflows/build-windows.yml` собирает установщик при push, pull request или вручную через вкладку **Actions**. Готовый установщик прикрепляется как artifact к запуску. После успешной сборки в ветке по умолчанию он также публикуется в GitHub Release как `VKSound-Setup-latest.exe`; ссылка на скачивание находится в начале `README.md`. Для CI скрипт запускается с параметром `-CI`, поэтому он не ждёт ответа в консоли.
